> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and locally install a generic Codex Ship Flow tool with isolated development, independent Review, deterministic Verification, human release gates, and crash-safe recovery.

**Architecture:** A Python 3.11+ standard-library CLI owns state, Git isolation, command execution, evidence, and release receipts. A Codex Skill provides the beginner-facing controller while the CLI mechanically prevents skipped or stale gates.

**Tech Stack:** Python standard library, `unittest`, Git worktrees, TOML via `tomllib`, JSON/JSONL evidence, Codex Agent Skill Markdown.
